# AGENT-004-F 离线知识体验复核 · 2026-11-13

本记录为助手对固定 Mock 输出和浏览器截图的内容/视觉复核，用户尚未验收；不是 Qwen 生成、人工评分基线或真实模型效果证明。

## 新旧行为

旧 Prompt 把检索词、待核实问题和文字记录设为 knowledge 默认，再要求 Proposal 不得承载知识解释，通用提示还要求 1–3 项思考/记录。材料能给出答案时，生成策略仍容易转向安排阅读作业。

新策略仅在 knowledge 生效：先解释一个材料支持的发现，再给一项比较、辨别或预测体验；1–3 步，不强制写作，第二项必须方式实质不同。有材料时允许解释和整合，Quest 复述事实必须带“本次用户提供的材料称”等归属与未核实语境。无材料至多一条获取资料方向。没有输出字符串删除器或隐藏校验错误。

## 公开材料

新输入：[knowledge_preview_material.json](../evals/knowledge_preview_material.json)，knowledge-preview-v1，public，2026-11-13 手工核对并简短中文转述。来源：[NOAA](https://oceanexplorer.noaa.gov/ocean-fact/bioluminescence/) 的定义/用途与不同化学体系，[Smithsonian](https://ocean.si.edu/ocean-life/fish/bioluminescence) 的 How it’s made / 引言中的诱饵、发光液、吸引配偶实例。没有复制全文或批量抓取；不将某一种荧光素/酶体系推广给全部生物。产品仅检查所贴文字的引用，不会自动访问参考URL或验证其内容。

固定演示的输入在 learning.py 中有显式匹配常量，专项测试确保它与 JSON 相等；这是 Mock 夹具，真实适配层不按材料特判。旧 CASE-01/02/04 和历史结果没有修改。

## A–E 逐项复核

| 输入 | 实际离线输出 | 体验判断及边界 |
| --- | --- | --- |
| A 新公开科学材料 | 解释光来自化学反应及部分机制的荧光素/酶作用；对比鱼诱饵吸引猎物与鱿鱼发光液迷惑捕食者；一条“两种用途”Quest | 能立即获得机制与用途区别。先想“改变了谁的行为”，再辨别“都为了捕食”是否准确，有短暂参与动作，无书面产出；仍是文字思考体验，没有交互测验或实物实验。 |
| B 只有观察次数（既有虚构Mock A） | 仅复述周一三次发光观察；一条辨别“描述观察/解释机制”的Quest | 可理解记录支持什么，但不能获得真实发光机制；这种材料价值有限，不能把它包装成科学课程。 |
| C 无关面包材料 | 无卡片、无Quest；一句材料依据不足或引用未通过说明 | 没有编造海洋知识；系统仍沿用统一门控提示，不能由这句错误语义区分所有不足原因。 |
| D 限定/冲突（既有Mock C和D分别预览） | 保留“部分/可能”或甲乙原有冲突，未知折叠展示，不判定哪条正确 | 没有长篇风险报告。限定/冲突案例仍有B类阅读辨别感，这符合弱材料边界，不宣称它们也提供机制知识。 |
| E 无材料 | 无卡片，一条获取标明出处科普短文的方向 | 没有科学讲解或三个重复写作任务。 |

六项质量问题：A 可以立即学到材料支持的知识点；A 的用途比较提供轻量参与，不再要求交记录；全部预览只有一个候选，不存在凑出第二条的问题，真实模型能否减量未知；卡片首先突出解释；来源状态始终一行可见，具体限制/校验/保存范围展开；Mock 本轮校验均通过且不审批，预算/审批保护另由完整回归和科学材料审批测试验证。引用合法不能自动证明语义忠实，也不能保证真实模型不注入或不编造。

## 视觉观察

助手实际打开了1440桌面完整结果、390移动卡片及展开截图，并查看冲突材料移动结果。首次截图发现全局panel段落样式压小解释文字，修复为更具体的选择器后重新生成并观察：解释为深色粗体较大字，关联次级、延伸问题浅底，来源标签换行完整；引用/限制/校验/保存说明收在原生details中。Enter/Space展开、focus可见、无横向溢出、历史Run刷新读回均已在浏览器验证。没有语音读屏器人工测试，不冒称已做。

为什么用户需要：直接理解感兴趣的知识，而非反复收到作业。Agent系统解决什么：调整生成的内容目标、减量策略与独立保存时的来源归属；前端层级属于UI/UX改进，不是模型能力提升。学到了什么：引用/预算合法仍可能没有学习价值，弱材料只适合有限解释；视觉层级必须看真实截图，CSS类名存在不能证明实际字号生效。

下一步只建议用户验收本次离线内容与页面。Qwen是否能稳定遵循新策略、自然解释、减少重复并保留限定，必须另获授权，以独立新批次和人工复核验证；旧v3批次不得补跑。
