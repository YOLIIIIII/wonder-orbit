# 知识解释质量人工规范

版本 `wonderorbit-learning-quality-v1`，案例 `wonderorbit-learning-cases-v1`。
来源：2026-11-08 用户 AGENT-004-C / EVAL-001 离线准备任务书。
仅观察 adapter_dto 与同一 DTO 的来源校验，不证明完整 Workflow、数据库或审批执行。

| 维度 | 0：明确错误或失去价值 | 1：部分符合、明显不足 | 2：主要要求满足 |
| --- | --- | --- | --- |
| evidence_faithfulness | 推导无支持事实或因果 | 大致有据但解释越界 | 忠实整合材料，说明证据边界 |
| qualifier_preservation | 将部分/可能变成全部/必然，掩盖冲突 | 有限定但遗漏关键范围 | 保留范围、条件和冲突 |
| relevance | 回答无关主题或硬凑依据 | 只有主题联系 | 对应用户具体问题及可回答部分 |
| learning_value | 误导或没有具体理解帮助 | 简单换词复述、收获有限 | 用比较或解释帮助形成具体理解 |
| uncertainty | 隐瞒缺口或声称材料已核实 | 泛泛提醒 | 指出本材料关键未知、未核实与不可推断内容 |
| follow_up_value | 无关或无法推进 | 有关但宽泛 | 具体自然，指向可补证据或理解缺口 |
| refusal_appropriateness | 无关材料硬解释，或无理由拒绝可用材料 | 边界基本合理但理由不足 | 恰当说明不足/冲突/恶意指令边界并安全澄清 |

所有维度缺人工判断、无可观察输出或不适用时为 `not_rated`，不是 0。
没有整体总分、自动合格线或自动语义评分。精确引用通过不能推出忠实性 2 分；
Mock 返回卡片不能推出学习价值 2 分。引用中的限定词被解释删掉、冲突被强行判真、
无关材料却引用准确，都需要人工阅读判断。

正确拒绝无关材料时，独立评价 refusal_appropriateness；无法观察的卡片学习价值等
标记 not_rated，并注明原因。无卡片不自动给 0 或满分。模型失败不是主动拒绝；
无合法 DTO 时不得评分其未观察到的解释。

人工记录字段：`score`（严格整数0/1/2或not_rated）、`note`（具体证据）、
`reviewer`、`reviewed_at`（YYYY-MM-DD）、`source`（用户反馈/人工审核来源）。
有分数时五字段必填。助手候选分不得冒充用户确认；source明确身份，待确认可保持not_rated。
程序只能检查格式及来源声明，不能认证评审身份或分数正确性。

先核对完整上下文、来源哈希、mode与模型配置，再比较原始DTO、gate和validated_output。
确定性失败与系统成功拦截可以同时成立。Fake / Mock / Live分别是工具自测、应用Mock和
外部提供但离线无法认证供应商的Live证据；不能合并为质量提升结论。

案例说明与命令见 [README](README.md#learning-quality-v1)。未来三例固定为CASE-01、02、04；
本规范不授权真实请求，真实质量与人工评审尚待单独授权执行。
